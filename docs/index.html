Try the Lunar world

  1. Open Play Minecraft 26.3 above and set your player profile.
  2. Choose Multiplayer → Direct Connection.
  3. Paste chillice_.lunarclient.world (without wss://), then join. Gaius includes a public RelayNode registry.
  4. If connection fails, confirm your friend has opened the world, selected Everyone, and is using the same Java version. If it says Invalid session, Failed to verify username, or Not authenticated, the issue is official Java account authentication; a transport relay cannot bypass it.

Important: This is a functioning browser client and launch page, but a successful join to this exact Lunar world has not been verified. Gaius's default local profile may not authenticate on online-mode servers. You may need a legitimately authenticated Minecraft Java session or another supported client. No password or account token should be entered into this page.

Optional: bring your own relay

Gaius has a public relay already. If it becomes unavailable or you want a restricted relay, deploy the relay in this repository to a Node-compatible HTTPS host. This does not require software on the Chromebook.
